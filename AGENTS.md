# Project Eclipse: правила для ИИ-агентов (Claude, Grok и др.)

Проект: ARPG (изометрия, PC). Движок: **Unity 6.3 LTS (6000.3.29f1)**, рендер **URP**, ввод через пакет **Input System**.
Приоритеты: 1) ощущение боя и силы, 2) читаемость, 3) реализуемость для маленькой команды. Никакого feature creep.

## Источники истины
- `Docs/Combat_Design_Document_v0.1.md`: спецификация боя (тайминги, ресурсы, формулы, Poise, статусы, juice).
- `Docs/Combat_Decisions_and_Next_Steps.md`: принятые решения D1-D7 и план.
- Числа и правила берём из CDD. Если нужно отклониться, объясни почему и пометь это в ответе, молча не меняй.

## Правила кода
- Namespace: `Eclipse.<Область>` (Player, Combat, Enemies, UI, CameraTools, DebugTools, EditorTools). Один публичный класс = один файл.
- Код лежит в `Assets/_Project/Scripts/<Область>/`, данные в `Assets/_Project/Data/`, сцены в `Assets/_Project/Scenes/`.
- Все игровые числа живут в ScriptableObject (как `PlayerTuning`), а не в коде. Это нужно для тюнинга без перекомпиляции.
- Ввод только через `Keyboard.current`, `Mouse.current`, `Gamepad.current` (Input System). Старый `UnityEngine.Input` не использовать. Геймпад поддерживаем наравне с клавиатурой.
- Время: `Time.deltaTime`. Тайминги в CDD заданы для 60 FPS, но логика не должна зависеть от частоты кадров.
- Не использовать DOTS/ECS на этапе прототипа. Пулинг врагов и снарядов добавим, когда понадобится.
- Не править `.meta` вручную. Не коммитить `Library/`, `Temp/`, `Logs/`.
- Комментарии краткие, на русском, со ссылкой на раздел CDD, где это уместно.

## Работа с редактором Unity
- Агент не запускает Unity. Всё, что можно сделать кодом, делай кодом. Ручную настройку в инспекторе заменяй Editor-скриптом с пунктом меню `Eclipse/...` (см. `Scripts/Editor/PrototypeSceneBuilder.cs`).
- После каждой задачи давай владельцу проекта: какие файлы добавлены, что нажать в редакторе, что должно получиться (чек-лист проверки) и что прислать при ошибке (текст из Console).
- Названия пунктов меню и окон редактора давай на английском, как в интерфейсе (редактор без русского языка).
- Небольшие задачи, один коммит на задачу.
